or long-running load test was performed. Those are deployment validation limits,
not successful tests claimed here. The scoreboard and existing AbilityGuard
interfaces provide currently available team/protection data; a separate clan
plugin would need to expose those relationships through an integration.

statistics with zero minted cash; optional money prizes require a funded treasury
UUID. A conventional Vault adapter is intentionally not invented: its ordinary
non-idempotent API cannot meet the local atomic payout contract. The implemented
existing-economy path satisfies the Phase 1/Phase 7 fallback without another coin.
Arena/capture positions require operator setup in a PvP-enabled world and must
respect external protection rules. Keep event rules unchanged while a persisted
competition is active, including during downtime. Disabled bounty modules retain
escrow; earned payouts still recover. No worlds or private configuration deleted.
