# PolderSMP cinematic resource pack

Original PolderCinematics 1.9 models, artwork and synthesized sound cues. Minecraft Java 1.21.11 (resource format 75.0). ZIP size: 100693 bytes.

This dedicated hosting branch preserves main and hosts only the cinematic asset addition. The plugin offers the pack additively; Minecraft asks players for consent. Do not use the GitHub file-page URL as a pack URL: use the raw HTTPS download at the pinned commit. SHA-1 is supplied beside the ZIP. No vanilla asset overrides; artwork/license/source references are inside the ZIP.
